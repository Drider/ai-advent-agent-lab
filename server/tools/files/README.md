# Файловые инструменты

Группа предоставляет агенту безопасный workspace для работы с текстовыми
файлами и PDF. Публичная точка входа — `server/tools/files/index.ts`.

## Инструменты агента

| Инструмент | Назначение |
| --- | --- |
| `find_files` | Найти обычные файлы по относительной glob-маске. |
| `read_file` | Прочитать один UTF-8 файл. |
| `read_pdf` | Извлечь текст выбранной страницы PDF. |
| `search_text` | Найти буквальную чувствительную к регистру подстроку по строкам. |
| `text_stats` | Посчитать строки, слова и Unicode-символы. |
| `write_file` | Создать новый UTF-8 файл без перезаписи существующего. |

Рабочая папка по умолчанию — `data/`. Все пути должны быть относительными
и оставаться внутри неё. Абсолютные пути, `..`, обратные слеши и симлинки
отклоняются.

## Примеры

Подготовьте файлы:

```bash
mkdir -p data/notes
printf 'TODO: первая задача\nГотово\n' > data/notes/a.md
printf 'TODO: вторая задача\n' > data/notes/b.md
mkdir -p data/documents
cp /путь/к/report.pdf data/documents/report.pdf
```

Примеры запросов в чате:

```text
Найди все файлы notes/*.md и покажи список.
Прочитай notes/a.md и notes/b.md, найди TODO и посчитай статистику.
Прочитай PDF documents/report.pdf и кратко перескажи его.
Собери TODO из notes/*.md и сохрани отчёт в reports/todo.md.
```

Прямое подключение группы:

```ts
import { createFileTools } from '~/server/tools/files'

const tools = createFileTools({ rootDir: '/tmp/my-agent-files' })
```

## Ограничения

- размер текстового файла, текста и содержимого записи — до 16 КиБ UTF-8;
- размер PDF — до 20 МиБ (20 × 1024 × 1024 байт); `read_pdf` читает одну
  страницу за вызов и возвращает до 16 КиБ текста. Если `nextOffset` не `null`,
  повторите вызов с теми же `path` и `page` и этим `offset`;
- PDF без текстового слоя возвращает пустой текст; OCR не выполняется;
- `find_files` возвращает до 50 путей и сканирует до 1000 записей;
- `search_text` возвращает до 100 совпадений;
- `write_file` создаёт родительские каталоги, но не перезаписывает файл;
- содержимое прочитанных файлов передаётся LLM-провайдеру как данные, а не как
  инструкции.

## Файлы

- `file-tools.ts` — AI SDK tools и схемы входных данных.
- `file-workspace.ts` — работа с корнем, путями, файлами и glob-поиском.
- `text-tools.ts` — поиск по тексту и статистика.
- `file-tool-contracts.ts` — лимиты, типы результатов и коды ошибок.
- `index.ts` — публичный API группы.
