# Инструменты конфигураций моделей

Эта группа управляет именованными профилями модели в общей базе SQLite. Профиль
содержит ID модели, необязательный лимит контекста, стратегию и её параметры,
настройки стоимости и подробную статистику. Правила использования агента и
точная схема также записаны в [SKILL.md](./SKILL.md).

## Инструменты

- `save_model_configuration` сохраняет профиль с точной схемой. Повторное
  сохранение имени без учёта регистра обновляет запись и сохраняет её ID.
- `list_model_configurations` показывает все сохранённые профили и полные
  параметры.
- `delete_model_configuration` принимает ID профиля, который был возвращён
  списком в этом же ходе. Сначала агент должен показать список и убедиться, что
  пользователь указал нужный профиль.

Изменения через агента выполняются только по явной просьбе пользователя. При
сохранении агент не должен придумывать неизвестные поля; валидатор отклоняет
лишние, пропущенные и неверно типизированные поля.
