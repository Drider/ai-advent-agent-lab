name: task-state
description: Follow the current task stage and request checked changes through the task tools.
---

Read the current task block on each step. Keep its goal, stage, expected action, and revision. When waiting for user input, record progress and ask the question. Submit artifacts before requesting a transition and run the checks specified for the current node. A workflow finishes with the exact checked result artifact. A basic task finishes with a saved result. On rejection, describe the reason and the next available action. Approval requires the user's explicit workflow action.
