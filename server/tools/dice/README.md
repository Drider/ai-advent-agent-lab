# Инструменты кубика

Группа отвечает за броски кубика и сохранение истории. Она подключается к
агенту через `server/tools/dice/index.ts`.

## Инструменты агента

### `rollDie`

Принимает `sides` — целое число от `2` до `1000`; если параметр не указан,
используется `d6`. Результат содержит количество граней и фактически выпавшее
число:

```json
{ "sides": 20, "result": 17 }
```

Каждый результат добавляется в `data/dice-rolls.csv`. Запись сериализуется в
одном процессе, поэтому параллельные броски не перемешивают строки.

### `listSavedRolls`

Возвращает историю в порядке записи. Если CSV ещё не создан, результатом будет
пустой массив `[]`.

## Примеры запросов в чате

```text
Брось кубик.
Брось d20.
Покажи сохранённые броски.
```

Для тестов или другого серверного кода фабрики можно импортировать из каталога
группы:

```ts
import { createDiceTool, createListSavedRollsTool, rollDie } from '~/server/tools/dice'

const result = rollDie(20)
const diceTool = createDiceTool()
const historyTool = createListSavedRollsTool()
```

## Файлы

- `dice-tool.ts` — валидация, AI SDK tools и случайный бросок.
- `dice-roll-csv.ts` — чтение и последовательная запись CSV-истории.
- `index.ts` — публичный API группы.
