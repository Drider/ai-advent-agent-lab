# Инструменты памяти

Группа подключает сохранение и отмену пользовательских фактов к существующим
репозиториям памяти. Новые факты не создаются автоматически: агент вызывает
`save_memory` только после прямой просьбы пользователя сохранить или запомнить
сведения. Уже сохранённое значение можно обновить по тому же ключу, когда
пользователь сообщает новую версию факта.

## `save_memory`

Инструмент сохраняет запись с ключом и значением:

- `working` — записи проекта категорий `goal`, `constraint`, `state`, `result`
  или `note`; текущий чат должен быть подключён к проекту. `goal`,
  `constraint` и `state` обновляются по ключу, `result` и `note` накапливаются;
- `long_term` — факты категорий `profile`, `decision` или `knowledge`;
- `profile` и `knowledge` обновляются по ключу, `decision` накапливается;
- `current_project` ограничивает долговременный факт проектом текущего чата;
- `global` делает долговременный факт доступным в любом проекте.

Просьба «сохрани в память проекта» по умолчанию означает
`working` / `current_project`, в том числе для знаний и решений: такие сведения
сохраняются в рабочем слое. Для изменяемых текущих фактов — например, выбранного
подхода, версии или статуса — используется `state`, чтобы новое значение заменяло
старое по тому же ключу. `note` оставляется для накапливаемых наблюдений и истории.
Тип содержимого сам по себе не переключает слой автоматически.
`long_term` выбирается только по явной просьбе сохранить в долговременную
память, глобально или для всех проектов. Глобальная область также требует
явного указания пользователя.

Инструмент использует проект и сессию текущего чата, поэтому модель не может
указать произвольный идентификатор проекта. Он возвращает статус (`created`,
`replaced`, `appended` или `stale`), сохранённую запись и предыдущее значение
при замене. Новый факт попадёт в подготовленный контекст со
следующего хода. Краткосрочная память остаётся историей диалога.

## `forget_memory`

Инструмент удаляет все записи с указанным ключом в выбранной области и
возвращает число удалённых значений. Для рабочей памяти доступна только область
`current_project`; для долговременной — `current_project` или явно запрошенная
`global` область. Удаление записывается в журнал изменений.

Примеры запросов:

```text
Сохрани в память проекта: используем SQLite.
Сохрани в рабочую память проекта: релиз планируем на декабрь.
Запомни глобально: отвечай мне по-русски.
Сохрани решение в долговременную память текущего проекта: используем SQLite.
```

`save_memory` доступен через публичную точку входа `index.ts`. Фабрика принимает
подключение SQLite и контекст текущего чата:

```ts
import { createSaveMemoryTool } from '~/server/tools/memory'

const saveMemoryTool = createSaveMemoryTool({ db, sessionId, projectId })
```
