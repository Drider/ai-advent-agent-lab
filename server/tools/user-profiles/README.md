# Инструменты профилей пользователя

Эта группа управляет текстом предпочтений, который агент получает отдельно от
долговременной памяти. `list_user_profiles` показывает названия и ревизии,
`get_user_profile` возвращает полную версию, а `create_user_profile`,
`update_user_profile` и `select_user_profile` меняют общую библиотеку или
назначение текущего диалога.

Создание, редактирование и переключение разрешены только по явной просьбе.
Изменения используются со следующего хода. Полные правила работы находятся в
[SKILL.md](./SKILL.md).
