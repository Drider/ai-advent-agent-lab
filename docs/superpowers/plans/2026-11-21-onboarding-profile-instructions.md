# Осмысленная инструкция профиля из анкеты — план реализации

> **Для исполнителей:** выполнять задачи последовательно с использованием TDD.

**Цель:** при завершении анкеты сохранять в профиле понятные пользовательские инструкции вместо списка исходных вопросов.

**Архитектура:** изменить только `formatOnboardingInstructions` в `server/tasks/onboarding.ts`; ответы анкеты сопоставляются с фиксированными русскими подписями и форматируются по одной строке. Логику имени профиля, сохранения и выбора профиля не менять.

**Стек:** TypeScript, Vitest, SQLite-репозитории текущего проекта.

**Спецификация:** согласованный формат:

```text
Обращаться к пользователю - <Имя>
Сфера интересов пользователя - <ответ>
Цель использования ассистента - <ответ>
Уровень пользователя в его сфере - <ответ>
Стиль ответов - <ответ>
```

## Ограничения

- Порядок строк фиксирован: name, role, goal, level, style.
- Для отсутствующего ответа сохраняется существующее значение `—`.
- Имя профиля и автоматический выбор профиля остаются без изменений.

## Фокус проверки

- Все пять ответов должны попасть в инструкцию под новыми осмысленными подписями.
- В инструкции не должно остаться заголовка `Анкета пользователя:` или исходных формулировок вопросов.
- Существующий сценарий создания и выбора профиля должен продолжить работать.
