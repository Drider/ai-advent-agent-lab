# Memory Selection Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Применить согласованные правила отбора памяти при каждом ходе.

**Architecture:** Чистый отбор записей по словам и бюджету подключается к существующей сборке снимка. Текущая реплика передаётся до её сохранения. Предпросмотр использует тот же отбор, события подготовки сохраняют причины исключения.

**Tech Stack:** TypeScript, Nuxt, better-sqlite3, Vitest; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-19-memory-selection-design.md`

## Global Constraints

- Сохранять изоляцию проектов, неизменяемость снимка и существующие стратегии краткосрочной памяти.
- Не сохранять ключи, значения и текст запроса в статистике.
- Не менять и не коммитить посторонние незавершённые правки в рабочем каталоге.

## Review Focus

- Текущая реплика ещё не записана в историю: она должна влиять на отбор.
- Продолжение и повторы запросов не должны дублировать текущую реплику в поисковом контексте.
- Большая необязательная запись не должна вытеснять обязательные или блокировать меньшие записи.
- Устаревшие события статистики должны читаться после миграции.
- Отбор и предпросмотр должны учитывать одинаковую сериализацию и независимые бюджеты.

## Проверка реализации

270 тестов в 45 файлах прошли; `nuxt typecheck`, `nuxt build` и `git diff --check` завершились успешно. HTTP-проверка production-сборки на временной базе подтвердила отбор предпросмотра, исключение отключённых записей, PATCH/DELETE обоих слоёв и SSR страницы памяти. Рабочая база не использовалась.

Независимый review выявил ложные совпадения по предлогам, повторную сериализацию растущего блока и некорректную обработку составных Unicode-слов. Исправления проверены регрессионными тестами; подсчёт бюджета теперь суммирует сериализованные байты с учётом экранирования и проверяется на точной границе. Отбор 5 000 коротких записей с бюджетом 100 000 токенов занял около 9 мс в локальном контрольном прогоне.
