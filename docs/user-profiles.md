# Профили пользователя

Профиль задаёт дополнительные инструкции для ответов агента: предпочтительный стиль, формат и ограничения. У каждого диалога выбран ровно один профиль. Профили хранятся в общей библиотеке, поэтому один и тот же профиль можно использовать в нескольких диалогах.

Профиль не является слоем [памяти агента](agent-memory.md). Его полный текст подключается к каждому ходу выбранного диалога независимо от отбора записей памяти и стратегии сжатия истории.

## Как пользоваться

1. Откройте страницу `/profiles` через кнопку «Управление профилями» в шапке чата.
2. Нажмите «Создать профиль», укажите название и дополнительные инструкции, затем сохраните профиль. Например: «Отвечай по-русски. Сначала дай краткий вывод, затем перечисли шаги».
3. Вернитесь в нужный диалог и выберите созданный профиль в поле «Профиль» в шапке чата.

Создание профиля само по себе не назначает его диалогу и не делает профилем по умолчанию. Чтобы новые диалоги получали его автоматически, откройте профиль на странице `/profiles` и нажмите «Использовать по умолчанию».

На странице профилей можно изменить название и текст инструкций. Список показывает текущую ревизию каждого профиля и пометку «По умолчанию». При переходе к другому профилю или уходе со страницы приложение предлагает подтвердить сброс несохранённого черновика.

## Когда изменения начинают действовать

| Действие | Результат |
| --- | --- |
| Выбор профиля в шапке чата | Меняет только текущий диалог. Следующее сообщение использует выбранный профиль. Во время генерации выбор недоступен. |
| Редактирование профиля | Следующий ход каждого диалога, которому назначен профиль, использует новую версию. Уже выполняющийся ответ сохраняет прежний снимок. |
| Смена профиля по умолчанию | Влияет на новые диалоги. Назначения существующих диалогов не меняются. |
| Создание ветки | Ветка наследует профиль родительского диалога на момент создания. Дальше выбор профиля у каждой ветки независим. |

При первом запуске или обновлении существующей базы приложение создаёт пустой профиль «Основной». Он назначается существующим диалогам и становится профилем по умолчанию. Пустые инструкции допустимы: профиль остаётся назначенным, но не добавляет пользовательских предпочтений.

Перед началом хода сервер считывает назначенный профиль и фиксирует его название, ревизию и полный текст инструкций. Один снимок действует на всех шагах этого хода, в том числе после вызовов инструментов. Команда продолжения запускает новый ход и получает актуальную версию профиля.

Инструкции профиля добавляются к базовым инструкциям агента отдельным блоком. Они задают предпочтения для ответа, но не отменяют базовые правила агента; более конкретная просьба в текущем сообщении может уточнить стиль или формат. Этот блок не превращается в сообщение истории, не попадает в сводку Summary или автоматически собранные Sticky Facts и учитывается при оценке заполнения контекстного окна. Если обязательный контекст с профилем не помещается в заданный лимит, сервер возвращает ошибку вместо обрезания профиля.

## Управление из чата через агента

По явной просьбе агент может показать список профилей, прочитать выбранный профиль, создать или изменить профиль и переключить профиль текущего диалога. Например: «Покажи мои профили», «Создай профиль “Кратко” с инструкцией отвечать в двух предложениях» или «Выбери профиль “Кратко” для этого диалога».

Агент не создаёт и не меняет профиль на основании поведения пользователя или записей памяти. Перед содержательным редактированием он читает полный текст профиля и сохраняет инструкции, которых просьба не касается. Если название неоднозначно, агент уточняет выбор. Созданный агентом профиль нужно выбрать отдельно; сменить профиль по умолчанию можно на странице `/profiles`.

Инструмент агента может переключить профиль только для диалога, в котором выполняется его активный ход. Текущий ответ при этом продолжает использовать исходный снимок; новый выбор действует со следующего хода. При безопасном продолжении прерванного хода агенту доступны только инструменты чтения профилей.

## Поля и сохранение

Профиль содержит `id`, `name`, `instructions`, `revision`, `createdAt` и `updatedAt`. Название после удаления внешних пробелов должно содержать от 1 до 80 символов. Инструкции могут быть пустыми; максимальная длина — 16 000 кодовых единиц UTF-16. Форматирование внутри текста сохраняется.

Названия уникальны после Unicode-нормализации NFKC, приведения к нижнему регистру и удаления внешних пробелов. Поэтому профили «Кратко» и « КРАТКО » одновременно создать нельзя. При редактировании клиент передаёт `expectedRevision`: если профиль уже изменён в другой вкладке, сервер возвращает конфликт, а форма сохраняет черновик и предлагает загрузить актуальную версию.

Профили, значение по умолчанию и назначения диалогам хранятся в `data/chat.sqlite`. Таблица `user_profiles` содержит тексты и ревизии, `user_profile_settings` — ID профиля по умолчанию, а `sessions.user_profile_id` — назначение диалога. В сохранённой конфигурации каждого хода также остаются эффективные инструкции и ID с ревизией использованного профиля. Установка профиля не ограничивает доступ к истории, инструментам или памяти: в приложении нет авторизации и разделения профилей по пользователям.

## HTTP API

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/user-profiles` | Вернуть краткий список без текста инструкций и ID профиля по умолчанию в поле `defaultProfileId`. |
| `POST /api/user-profiles` | Создать профиль из `name` и `instructions`; вернуть полный профиль. |
| `GET /api/user-profiles/:id` | Вернуть полный профиль. |
| `PATCH /api/user-profiles/:id` | Изменить `name` и/или `instructions` с обязательным `expectedRevision`; остальные поля сохранить. |
| `PATCH /api/user-profiles/default` | Назначить существующий профиль по умолчанию через `{ "profileId": "..." }`. |
| `PATCH /api/sessions/:id/user-profile` | Назначить профиль диалогу через `{ "profileId": "..." }`, если в нём нет выполняющегося хода. |

API возвращает `400` при неверных данных, `404` при отсутствии профиля или диалога и `409` при конфликте названия, ревизии или попытке переключить занятый диалог. Ответы маршрутов профилей и назначения профиля имеют заголовок `Cache-Control: no-store`.

## Ограничения

В текущей версии нет удаления, импорта и экспорта профилей, профилей на уровне проекта или объединения нескольких профилей для одного диалога. Изменение профиля не переписывает старые ответы и сохранённые сводки истории.

Сведения о трёх слоях памяти приведены в [документации по памяти агента](agent-memory.md), а правила создания независимых веток — в [документации по ветвлению](chat-branching.md).
